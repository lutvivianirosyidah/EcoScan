{% if jenis == 'baterai_bekas' %}
✓ Jangan membongkar, membakar, atau merendam baterai.
✓ Simpan sementara di tempat kering, jauh dari anak-anak.
✓ Cegah terminal baterai bersentuhan dengan benda logam.
✓ Serahkan ke titik pengumpulan atau pengelola limbah yang menerima baterai.
{% elif jenis == 'sampah_elektronik' %}
✓ Pisahkan perangkat elektronik dari sampah rumah tangga biasa.
✓ Jangan membongkar baterai atau komponen internal sendiri.
✓ Hapus data pribadi dari perangkat yang masih bisa diakses.
✓ Salurkan ke pengumpul atau fasilitas e-waste yang sesuai.
{% elif jenis == 'puntung_rokok' %}
✓ Jangan menyentuh atau mengumpulkan puntung rokok secara langsung.
✓ Jangan membakar puntung rokok untuk mengolahnya.
✓ Jauhkan dari anak-anak dan hewan peliharaan.
✓ Ikuti panduan petugas kebersihan atau pengelola sampah setempat.
{% elif jenis == 'sampah_residu' %}
✓ Gunakan bahan yang bersih dan tidak terkontaminasi.
✓ Jangan gunakan masker bekas pakai untuk membuat boneka.
✓ Gunakan pelindung saat menangani pecahan keramik.
✓ Pilah kembali bahan yang sebenarnya masih dapat digunakan atau didaur ulang.
{% else %}
✓ Pisahkan sampah sesuai jenis materialnya.
✓ Kosongkan dan bersihkan sisa makanan atau minuman.
✓ Keringkan kemasan sebelum digunakan kembali.
✓ Pastikan bahan dan alat yang digunakan aman.
{% endif %}
